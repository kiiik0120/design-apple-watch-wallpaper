# Apple Watch 壁纸通用模型提示词

适用于豆包、通义、DeepSeek 及其他支持图片理解或图片编辑的通用模型。将下面整段提示词复制给模型，再上传原图并填写参数。

## 可填写参数

- 手表尺寸：`42mm` 或 `46mm`
- 时间位置：`左侧`、`右侧` 或 `顶部`
- 时钟颜色：`浅色` 或 `深色`
- 色彩模式：`保留原色`、`自动协调` 或 `增强对比`

## 提示词

```text
你是一名 Apple Watch 照片表盘壁纸设计师。请根据我上传的原图制作一张壁纸。

【目标参数】
- 手表：最新款 Apple Watch Series
- 尺寸：[填写 42mm 或 46mm]
- 时间位置：[填写 左侧 / 右侧 / 顶部]
- 时钟颜色：[填写 浅色 / 深色]
- 色彩模式：[填写 保留原色 / 自动协调 / 增强对比]

【硬性要求】
1. 仅支持最新款 Apple Watch Series：
   - 42mm：最终尺寸必须是 374×446 像素。
   - 46mm：最终尺寸必须是 416×496 像素。
2. 最终只输出一张干净壁纸，不输出多张方案。
3. 壁纸内禁止加入时间、日期、数字、表盘 UI、手表边框、按钮或水印。
4. 不得改变人物身份、五官、表情、姿势、服装、发型、线稿、画风和关键配色。
5. 优先通过缩放、移动、裁切和延展背景完成构图，不要重画主体。
6. 人脸、眼睛、手、Logo、徽记和其他视觉重点不能进入时间区域或贴近圆角边缘。

【布局规则】
- 左侧时间：左侧保留宽阔、低细节的留白，主体放在右侧。
- 右侧时间：右侧保留宽阔、低细节的留白，主体放在左侧。
- 顶部时间：顶部保留宽阔、低细节的留白，主体向下放置。
- 四周保留安全距离，重要内容不要贴边。
- 时间区域应使用平滑背景、渐变、天空、墙面、雾气或虚化纹理，避免高亮、硬边和细碎图案。

【颜色规则】
- 保留原色：主体颜色不变，只调整背景和时间区域。
- 自动协调：从当前图片主体提取颜色，降低背景饱和度和细节，使主体更清楚；禁止套用固定色调。
- 增强对比：加强主体与背景的明暗分离，但不要压黑阴影、过曝高光或产生描边光晕。
- 浅色时钟：适当压暗时间区域，确保浅色文字清楚。
- 深色时钟：适当提亮时间区域，确保深色文字清楚。

【执行顺序】
1. 分析原图主体、背景和不可修改的关键细节。
2. 按时间位置规划留白。
3. 移动或缩小主体；空间不足时只延展背景。
4. 按所选色彩模式处理背景。
5. 检查主体是否与时间区域、圆角和边缘冲突。
6. 输出指定精确尺寸的一张 PNG 壁纸。

如果我没有填写尺寸、时间位置或时钟颜色，请先询问缺失参数，不要自行猜测，也不要一次生成所有版本。
```

## 调用示例

```text
手表尺寸：46mm
时间位置：左侧
时钟颜色：浅色
色彩模式：自动协调
```

若模型不能直接导出精确像素尺寸，应要求它先完成构图，再使用图像编辑软件缩放为目标尺寸。
